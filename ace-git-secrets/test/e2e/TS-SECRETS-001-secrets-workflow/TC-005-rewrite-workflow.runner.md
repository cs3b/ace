# Goal 5 — Rewrite Workflow (Saved Report Contract)

## Goal

Verify rewrite dry-run behavior using the saved scan report contract:
- `scan` produces a persisted report with `raw_value` token fields
- `rewrite-history --dry-run --scan-file <saved-report>` succeeds
- git HEAD remains unchanged after dry-run

## Workspace

Save all output to `results/tc/05/`. Capture:
- `results/tc/05/saved-report.json` — copy of that persisted report
- `results/tc/05/dry-run.stdout`, `.stderr`, `.exit` — rewrite dry-run output using `--scan-file`
- `results/tc/05/before-head.txt` and `results/tc/05/after-head.txt` — commit hash before/after dry-run

## Constraints

- Do not validate `raw_value` by scraping ad-hoc stdout; validate from `saved-report.json`.
- Use a saved report generated by real `scan` execution as dry-run `--scan-file` input.
- `before-head.txt` and `after-head.txt` must come from real `git rev-parse HEAD` executions.
- All artifacts must come from real tool execution, not fabricated.
