# Goal 3 — Issue linkage lifecycle and uncertain recovery

Evaluate final disposable repository/product state first, then harness observations and canonical product receipts, with command exits as supporting evidence. Missing required inputs, unexecuted variants, generic success acknowledgements or missing canonical correlation fail this TC; never convert them into PASS or optional skips. Bind each observation to the supplied installed manifest and exact candidate. Cite actual artifact paths and commands, not runner prose. No fixture is installed proof.

Require local CRUD/hierarchy state; remote link/repeat/sync/close/reopen/clear state agrees with exact issue identity. Ownership conflict cannot replace ownership. Lost reply/restart must retain pending identity and reconcile without a duplicate semantic effect or fallback. Missing remote observation leaves uncertainty unresolved.
