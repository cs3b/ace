# Shared design assumptions

Start from the audience, task, existing brand and constraints. Prefer concrete hierarchy and useful content over decorative novelty. Treat these as adaptable starting points, never universal aesthetic bans.

Preserve user intent and existing design language. Make primary actions identifiable; provide visible focus, meaningful labels, readable contrast and responsive reflow. Prefer familiar interaction patterns unless a departure helps the task. Respect reduced-motion needs.

During exploration use one language, common mock data, minimal runnable artifacts and a small scope. Production integration, complete states and engineering verification follow explicit direction selection.
