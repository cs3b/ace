## Behavioral Specification

Review-safe bundle loading uses an explicit source trust policy and explains why each accepted source was admitted.

### User Experience

## Interface Contract and Success Criteria

- [ ] SC1: General-purpose bundle code no longer chooses an ace-review package exception; the caller supplies policy from trusted configuration with explicit provenance.

- [ ] SC5: A PR cannot authorize its own outside-root sources through modified project configuration.
