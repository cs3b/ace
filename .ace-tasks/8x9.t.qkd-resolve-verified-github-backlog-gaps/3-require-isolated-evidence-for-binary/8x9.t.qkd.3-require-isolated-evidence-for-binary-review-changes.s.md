# Require isolated evidence for binary review changes

## Behavioral Specification

A binary change can satisfy review coverage only with exact-artifact verification evidence produced in an isolated environment; text inventory alone is insufficient.

### User Experience

Input and expected output are defined by the concrete scenarios in `ux/usage.md`. Normal completion reports its result; failure identifies the unmet condition without claiming success.

## Verification Baseline — 2026-10-10

The issue describes removed --verify-session/--final-session paths. Current DiffScope retains binary_files, and a direct producer-to-validator probe shows full_pr_coverage! accepts a binary-only manifest with matching head/base and inventory. This proves a coverage-boundary gap, not an end-to-end campaign acceptance bypass. No binary receipt consumption was found in current campaign evidence.

## Interface Contract and Success Criteria

- [ ] SC1: Without a valid alternative receipt, a binary-only or mixed PR cannot claim complete binary verification or accepted delivery.
- [ ] SC2: The supported verification path cannot read reviewer credentials, access network, or write outside its disposable workspace; unsupported environments refuse explicitly.
- [ ] SC3: Only trusted policy outside PR control authorizes the verifier; exact head/base, artifact digest, verifier identity/arguments, output digest and exit status are durably bound to its receipt.
- [ ] SC4: Stale SHAs, modified artifacts, forged receipts, failed/incomplete verification and PR-supplied policy cannot satisfy coverage.
- [ ] SC5: The current campaign and Assign evidence flow consumes this receipt. No obsolete parallel review gate is restored.

## Verification Plan

- Adversarial fixture attempts credential read, network access and writes outside the disposable root; assert denial.
- Stale/replayed receipt, changed bytes, changed base policy, failed verifier and unsupported-platform controls.
- Run tests for the actual selected isolation owner; a stubbed sandbox is not evidence of containment.
