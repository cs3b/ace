# Honor AGY configuration and deliver large prompts

## Behavioral Specification

AGY completes one-shot review-sized prompts through bounded argument or file delivery and honors the same configuration regardless of YAML key representation.

### User Experience

Input and expected output are defined by the concrete scenarios in `ux/usage.md`. Normal completion reports its result; failure identifies the unmet condition without claiming success.

## Verification Baseline — 2026-10-10

Confirmed without a model call: AgyClient initialized with string-key max_prompt_length=400000 rejects 354141 bytes at the default 100000 limit. build_agy_command only embeds the prompt in argv; no large-prompt file delivery exists. Existing 135 provider tests pass but do not cover this YAML-key reproduction.

Revision: `aaf6dfec4c2d93c8f0b1c7cd53b6a07c68942659` (HEAD and fetched origin/main). See the parent triage report for executed tests and limitations.

## Interface Contract and Success Criteria

- [ ] SC1: String-key YAML and equivalent symbol-key options, including generation_config, produce the same effective byte threshold; invalid values fail before dispatch.
- [ ] SC2: A 354141-byte prompt is delivered completely using a supported file-read mechanism with the minimum necessary headless read permission; argv remains bounded.
- [ ] SC3: Small prompts use the existing direct path; multibyte thresholds are measured in bytes and no content is silently truncated.
- [ ] SC4: Temporary prompt material is available throughout execution and cleaned up after success, timeout, interruption and failure; refusal to read the file is an explicit delivery failure.
- [ ] SC5: No global tool-permission bypass is enabled to make file transport work.

## Verification Plan

- Capture native argv, file contents and permissions with controlled transport for below/at/above threshold and Unicode inputs.
- Exercise YAML-to-client configuration, success, denied read, timeout and interrupted subprocess cleanup.
- At implementation time inspect the installed AGY CLI capability contract; run a separately authorized headless smoke test to prove actual file reading. Deterministic tests alone do not prove native CLI permission support.
