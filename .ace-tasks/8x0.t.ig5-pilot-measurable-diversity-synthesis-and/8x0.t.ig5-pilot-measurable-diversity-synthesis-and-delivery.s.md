# Pilot measurable diversity synthesis and delivery

## Behavioral Specification

An operator can run one bounded multi-model discovery, synthesis and final-delivery pipeline and compare its quality/economics with a single-discovery control and Astra end-to-end. This is a measurable pilot, not an autonomous factory or an assertion that a named model is superior.

## Ownership and Decomposition

Owner: **ace-assign**, consuming ace-review policy and existing Lab routing/authority. Size: **large**. This parent is an orchestrator only; each original intention is a real child. R1-R3 (`8x0.t.ig2` -> `8x0.t.ig3` -> `8x0.t.ig4`) establish the review foundation first.

| Plan | Task | Outcome | Dependencies |
|---|---|---|---|
| L1 | `8x0.t.ig5.0` | Run isolated discovery candidates from one baseline | 8x0.t.ig4, 8wr.t.qjl |
| L2 | `8x0.t.ig5.1` | Distill anonymous candidates into a portable contract | 8x0.t.ig5.0, 8x0.t.ig5.3 |
| L3 | `8x0.t.ig5.2` | Deliver final candidates with authorized model escalation | 8x0.t.ig5.1, 8wr.t.qkb |
| L4 | `8x0.t.ig5.3` | Preserve verified invariants and adversarial probes | 8x0.t.ig4 |
| L5 | `8x0.t.ig5.4` | Compare three pipelines with complete cost evidence | 8x0.t.ig5.2, 8x0.t.ig5.3 |

L4 can proceed after R3 alongside L1 and must feed L2; the graph is acyclic. L3 additionally consumes existing provider-neutral delivery `8wr.t.qkb`. `8wr.t.qjl` supplies durable attempts/receipts. No second execution authority is introduced.

## Interface Contract

The existing assignment system exposes discover-only, synthesis, final-delivery and benchmark stages with explicit artifact handoffs and status. Child specs own the concrete contracts. Default routing is GLM/Gemini/DeepSeek Flash discovery -> Sol synthesis -> fresh GLM Flash implementation -> independent Sol review. Exact provider/model bindings are preflighted configuration; unavailable families are not silently replaced. Astra escalation requires a recorded reason and applicable authorization.

## Success Criteria

- [ ] SC1: All five children deliver their observable outcome with positive and failure-path evidence; no major goal remains only in parent prose.
- [ ] SC2: Discovery remains isolated and bounded; only the final candidate enters full delivery with independent current-head review and authorized external actions.
- [ ] SC3: A fresh implementer can use the frozen synthesis and applicable invariant/probe package without previous conversations.
- [ ] SC4: Three fresh tasks across three arms produce nine planned pipeline cells with fair common acceptance and complete known-cost accounting; failed/blocked cells and unknown measurements remain visible.
- [ ] SC5: The report can conclude no advantage or insufficient data; cost reduction never substitutes for correctness, and no default strategy changes automatically.

## Verification Plan

Children own unit, integration and negative-path tests. Parent acceptance follows one complete artifact chain through existing attempts/receipts, checks all child evidence and the nine-cell report, and independently evaluates final quality blind to model identity/cost. Draft creation does not execute this pilot.

## Decisions and Limits

Approved scope: pilot plus measurement, three comparison arms, three new task categories and one run per task/arm. This small sample is exploratory. Cross-arm output sharing is prohibited until final evaluation. A/B/C is calibration/provenance, not a fresh effectiveness sample. No rollout, model deployment, benchmark run, merge or modification of Nervus PRs #175-177 is included in this drafting task.
