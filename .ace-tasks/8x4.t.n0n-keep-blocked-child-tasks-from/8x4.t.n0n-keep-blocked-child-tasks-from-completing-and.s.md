# Keep blocked child tasks from completing and archiving their parent

## Observed defect — 2026-10-05

During source-only closure, `bin/ace-task update 8wr.t.qkb.0 --set status=done,needs_review=false` changed the child but returned `Task '8wr.t.qkb.0' not found`. Immediate show found parent qkb marked done and archived while qkb.1 remained blocked. Root restored qkb to blocked/root using `bin/ace-task update 8wr.t.qkb --set status=blocked --move-to next`; show confirmed child .0 done and .1 blocked. No product fix is claimed.

Source evidence: FolderCompletionDetector::TERMINAL_STATUSES includes done/skipped/blocked. TaskManager check_auto_archive delegates this classification and can archive a parent before returning the updated child. This contradicts blocked meaning an unresolved required outcome. No repeated mutating reproduction was performed against user tasks.

## Outcome and contract

Updating a child to done must preserve a parent and sibling with unresolved work. Blocked is not completed work and never independently authorizes parent done/archive. Public update must return the updated child reliably, even when a legitimate whole-family archival occurs. Explicit parent archive requests must not silently convert unresolved children to completion.

One small source slice in ace-task/shared completion detection. Determine all consumers of the shared terminal classification during review, including doctor and idea/task archival. Keep skipped/cancelled explicit terminal semantics consistent with documented task policy; never rewrite historical records wholesale.

## Success criteria

- [ ] Parent with one done child and one blocked child stays at its prior nonterminal status/location; sibling status and evidence remain unchanged.
- [ ] Pending/draft/in-progress siblings likewise prevent automatic completion/archive.
- [ ] Legitimately complete family archives as specified and update returns the requested child rather than post-move not-found.
- [ ] Update/show/list/doctor agree on resulting state; no incorrect doctor fix archives blocked work.
- [ ] Independent source review and actual isolated CLI regression/package tests pass.
