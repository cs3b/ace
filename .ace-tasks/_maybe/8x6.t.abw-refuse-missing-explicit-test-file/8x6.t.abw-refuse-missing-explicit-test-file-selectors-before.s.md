# Refuse missing explicit test file selectors before execution

## Behavioral specification

An explicit Ruby test file selects that file or fails before any test starts. A missing file must never disappear from selection and broaden the run to a package/layer. This is one standalone CLI correctness slice, advisory size small, outside the Lab critical path; no automatic promotion or implementation is authorized by this draft.

## Interface contract

`bin/ace-test PACKAGE LAYER FILE.rb` and package-relative, package-prefixed, absolute and `FILE.rb:LINE` forms retain their existing successful meanings. If any explicit file does not resolve to a readable regular test file, return a nonzero input error identifying that selector before spawning a runner or evaluating tests. A mixed valid/missing list also fails as a whole; argument order cannot silently discard the missing entry. Existing named targets and supported pattern selection remain distinct; no fallback from an explicit `.rb` or `.rb:LINE` path to a named target/layer. Quiet mode still reports this error. Do not change unrelated test execution or line-filter semantics.

## Success criteria

- [ ] Missing explicit file, with or without a named layer, causes a clear nonzero error and zero runner starts.
- [ ] Mixed selectors and all supported path forms preserve the same refusal; no partial or expanded execution.
- [ ] Existing valid explicit selection and named target/pattern usage still select their documented tests, without evaluating unrelated files.

## Verification plan

Use temporary harmless fixture files and the actual parser/orchestrator boundary. Record selected file sets and whether a controlled runner is called; test the invalid case without launching package suites. A small isolated CLI integration fixture should prove nonzero status and absence of a sentinel test execution. Include valid file, valid file:line, missing file, valid+missing in both orders, package-relative/prefixed/absolute paths and existing named target/pattern selection. Run only the inspected focused `bin/ace-test` regression after implementation; a missing-selector reproduction must not intentionally run ambient or native tests.
