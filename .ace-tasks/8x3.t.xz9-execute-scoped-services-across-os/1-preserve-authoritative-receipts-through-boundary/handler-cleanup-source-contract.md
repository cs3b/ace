# Bounded original handler cleanup — source contract

This implements the independently approved xz9.1 responsibility direction; exact code approval remains pending. Existing Herdr BoundedProcess owns subprocess IO and bounded cleanup; no controller, privileged operation or ledger is introduced. Ordinary successful generic calls preserve their prior behavior and never newly signal their group.

ProtectedServiceHandler selects owned-group cleanup with the existing closed environment and 30-second execution deadline, stdout16KiB and stderr8KiB retained caps. Process.spawn creates the original process group; the owner retains the original child unreaped. Stream EOF is not termination: after both streams close, waitid(P_PID, original_pid, WEXITED|WNOHANG|WNOWAIT) must positively observe termination before success cleanup signals the group. The unreaped original leader pins its identity through that signal. Only then may waitpid reap. An observed loss of exclusive child ownership (ECHILD) refuses and permanently prohibits signalling that retained numeric group. No detached normal waiter may race this owner.

Timeout/IO failure signals only the still-unreaped owned group, closes owned pipes, and attempts reaping for at most one additional second. Unconfirmed cleanup returns post-launch uncertainty, never a service receipt or domain no-effect assertion. Only while exclusive original-child ownership remains intact may the unresolved child be transferred to Process.detach for eventual reaping; the caller never waits on that reaper and never signals or produces positive proof after transfer. ECHILD prohibits both signalling and transfer. Successful process-group cleanup is not proof arbitrary domain effects/escaped writers are absent; SC5 still requires the original domain inspector and canonical challenge/import authentication. No PID/time discovery can recover ownership.

Primary ABI references (read-only research, no host probe): [Linuxv6.12 wait options](https://raw.githubusercontent.com/torvalds/linux/v6.12/include/uapi/linux/wait.h), [XNU wait header](https://raw.githubusercontent.com/apple-oss-distributions/xnu/main/bsd/sys/wait.h). Both select P_PID=1, WEXITED=4 and WNOHANG=1; WNOWAIT is Linux0x01000000 versus Darwin0x20. Code uses a zero-initialized bounded siginfo buffer and accepts only SIGCHLD for the exact selected child. Unsupported/unavailable observation refuses; it cannot infer exit from EOF.

Controlled source tests inject the spawn/wait/termination-observation boundary and use ordinary pipes. They exercise live child after EOF, signal-before-reap ordering, generic no-success-signal behavior, ECHILD refusal, bounded unconfirmed cleanup, separate caps and actual handler receipt/error interpretation. They do not execute waitid/native/protected/descendant probes and do not satisfy gad.2 installed effectiveness.
