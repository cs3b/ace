# Make integration handoff actionable: accepted attempts, real Forgejo terminal results, serial advance

Captain-authorized real patch (host w9b umbrella updated separately; this is the owning ACE
child). Delivers the smallest reviewed patch making the integration handoff actionable end-to-end:
dispatch → accepted attempt/start → terminal Forgejo result, queue advancing serially against
fresh main.

## Requirements (acceptance)

1. **CLI listen fix + non-mocked startup regression**: `ace-lab/lib/ace/lab/cli/commands/service.rb`
   `Listen#call` (~line 220) constructs `Organisms::OrdinaryMergeReceiver.new(config:, policy_document:)`
   without the required `coordinator:` (constructor at
   `organisms/ordinary_merge_receiver.rb:43`). Fix the construction and add a REAL non-mocked CLI
   startup regression (invoke the actual binary/CLI; assert serve is reached or a config refusal is
   emitted — never `ArgumentError` missing coordinator).
2. **ONE canonical Assign journal**: producer project coordinator and privileged executor must refer
   to the same authoritative journal with reviewed permissions — not an integration-checkout
   duplicate.
3. **Real Forgejo terminal result**: `remote_observation` (organisms/ordinary_merge_receiver.rb ~302)
   is currently derived from local `OrdinaryFfMerge` results — a relabelled local ref effect. The
   terminal receipt must prove the ACTUAL Forgejo PR state via API readback (merged flag, merge
   commit sha) of the exact PR identity. Local git effects (including update-ref) are not a Forgejo
   PR merge and must never be presented as one. Receiver must NOT update checked-out canonical main
   locally.
4. **Trusted scoped admission refresh**: `OrdinaryAdmissionResolver` snapshots exact-request grants at
   boot; sequential work requires trusted scoped authorization refresh/admission per candidate
   without root editing each candidate.
5. **Serial advance + uncertainty discipline**: accepted request ⇒ attempt/start in the canonical
   journal; the queue advances serially against fresh main; an unaccepted request is not a working
   integrator; an uncertain result reconciles (forge readback) before any repeat.
6. **Independent review attachment + carry-forward**: final-head review attachment to the PR and the
   independent carry-forward workflow (patch-id identity chain) are part of the handoff; the
   integrator/domain executor posting its own approval does NOT count as independent review.
7. **Timeout → actionable owner**: handoff timeouts name the actionable owner in the refusal/escalation
   instead of endless holding.
8. **Deploy contract (host installs; code consumes)**: scoped config under `/etc/lab/ace-lab/`
   (forge base URL + PR-read/comment-scoped token + service policy path), root-owned; receiver
   refuses with actionable "config missing: <path>" when absent. No credential bypass, no new Python
   bridge, no parallel queue.
9. **Deployed end-to-end acceptance**: two sequential PRs / rebase / merge against the real lab
   Forgejo, restart and lost-reply recovery, exercised via deployed CLI — source/fixture tests alone
   do not meet acceptance.

## Constraints

- Reuse existing Assign attempt/coordinator and ordinary receiver machinery (xz9.4 base at a5fc9c4b).
- No backward-compat layers; remove broken paths outright.
- Independent review required before integration; dedicated worktree; AGit topic push; host
  root integrator merges.
