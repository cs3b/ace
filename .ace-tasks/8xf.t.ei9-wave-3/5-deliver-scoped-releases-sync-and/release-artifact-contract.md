# Canonical ordinary release artifact retention

Source stage under ei9.5, following the approved ordinary publication plan.
This does not enable publication, install a runtime profile or resume blocked
communication work. Reuse Assign journal, TransferCodec and CanonicalEvidence.

## Closed producer and authorization contract

The actual running ordinary producer submits one built gem through a fixed
`retain_release_artifact` operation. It selects only its real assignment/attempt,
current head/candidate generation, pane, expected canonical generation, exact
release authorization reference and a closed manifest. The installed owner derives
project, native origin, accepted candidate head/tree/reference and independent
review itself. No protected launch ticket, local report or caller-selected journal
is an alternative proof.

Manifest fields: gem name, version, platform, registry, SHA256 and byte count.
Registry is exactly https://rubygems.org. The canonical binding adds project,
assignment/attempt and exact accepted candidate reference/head/tree. The existing
root-selected service policy authorizes the full canonical manifest digest and
exact RubyGems resource under operation publish; the artifact remains only a
retained input. Reading a release grant does not consume a publication permit.
Root-fixed decisions and existing canonical proposal authorization share that
policy owner; no separate release-decision database is created.

Before transfer, the owner checks actual native scope. After bounded byte receipt,
it verifies actual digest/size and gem metadata outside the journal write lock.
Each fresh CAS and replay rechecks native producer, current candidate, independent
review and current release authorization. Changed/revoked grants, candidates,
metadata or bytes refuse. The artifact import and accepted retention reply are
one canonical mutation. Retry retains the original request and imported bytes.

## Binary evidence contract

Keep existing review/result/service report limits unchanged. Add one fixed
TransferCodec purpose for a single nonempty gem, bounded to 64 MiB, and one
CanonicalEvidence kind with role worker and the same single-artifact bound.
Reuse its closed descriptor, provenance events, binding digest, SHA, canonical
blob storage and same-prefix reads. A report cannot select the binary limit.
No filesystem path is accepted as an artifact reference.

The accepted reply retains the manifest, exact candidate association and canonical
import reference. The later fixed publisher reads the exact retained bytes into
its own immutable staging, separately from accepted source. Fresh service claim,
original executor, publication continuation/OTP and registry reconciliation remain
mandatory; retention grants no service execution or publication success.

## Source freeze scope

The first vertical slice now retains one built gem through the public ordinary
socket, the existing canonical journal and actual metadata/digest checks. Current
installed owner selection, project visibility and existing exact ServicePolicy
or canonical proposal reader supply release authorization. Missing or revoked
authorizers refuse; retention does not dispatch, consume a grant or create an
executor claim. A reader verifies imported bytes against the same canonical
prefix for the later publisher. The protected publication input contract stays
unchanged; the ordinary fixed publication consumer and immutable artifact staging
remain the next source increment, rather than an implied installed capability.
