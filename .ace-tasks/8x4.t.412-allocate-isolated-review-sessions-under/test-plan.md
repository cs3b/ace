# Test responsibility map

Data integrity is high risk. Session identity and report/feedback attribution are verified with real temporary filesystem state, fixed clock values, barriers and separate manager instances; no paid provider is required.

| Behavior | Layer | Evidence |
| --- | --- | --- |
| Automatic candidate collision preserves historical bytes | fast organism | Existing candidate sentinel, returned isolated path |
| Invalid explicit nonempty/file/symlink path refuses before content/model | fast organism and CLI feature | Failure result/exit, unchanged bytes, no executor call |
| Unwritable allocator returns actionable path error | fast organism | Controlled EACCES boundary and no downstream execution |
| Cross-process automatic and empty-explicit races | feature | Forked workers released by pipes; distinct ownership or one winner |
| Fixed-clock concurrent preparation retains subject/prompt metadata | feature | Real execute_review calls with controlled config/content composition, process barrier |
| Both completion orders preserve output and feedback attribution | feature | Controlled model executor, real feedback publication and reader, distinct sentinels |
| Interruption leaves permanent explicit claim | feature | Interrupted owner process, subsequent refusal, intact other history |
| Equal-clock release reports preserve both session payloads | fast organism | Exclusive export allocation and immutable preexisting report |
| Existing single review/campaign/delta/evidence contracts | package | bin/ace-test ace-review all |

Mock only expensive provider/config/prompt boundaries. Filesystem allocation, metadata writes, release copies, feedback writers/readers and process synchronization are real. Permission refusal uses controlled EACCES because privileged runners can bypass mode bits. No timing sleeps or guessed completion order.
