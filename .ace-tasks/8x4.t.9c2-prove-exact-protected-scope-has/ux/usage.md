# Exact scope proof — draft usage

API surface: protected owner/runtime consumer contract; native mechanism and
exact public schema remain unresolved pending independent readiness review.

A mapped launcher/supervisor requests an owner-resolved observation of one
project/assignment/attempt after its worker exits. An original child exit with a
live descendant or permitted external-spawner writer returns running or
unverifiable and ownership remains held. No raw scope path/PID selection exists.

After the selected owner closes writer admission and positively observes the
exact immutable scope empty, closed_no_writers can be consumed by canonical
finish/stop. It does not settle pending service effects or inboxes. Restart,
identity replacement, unreadable evidence or an unsupported platform returns
unverifiable; cache or worker-reported absence never supplies a successful proof.

The task stays draft until the mechanism, exact schema and supported installer
boundary are selected and independently reviewed. These are acceptance goals,
not executable delivered calls.
