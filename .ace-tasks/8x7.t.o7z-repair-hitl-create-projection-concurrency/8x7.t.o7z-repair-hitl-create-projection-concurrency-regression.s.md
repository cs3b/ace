# Repair HITL create projection concurrency regression fixture

## Behavioral Specification

The create/deliver concurrency regression must exercise the maintained lifecycle
lock boundary: request persistence and initial public projection happen under one
request lock. A competing broker may read the published request but cannot commit
delivery before creation releases that lock. Repeated initialization of the same
incarnation after delivery must preserve `answer-delivered` and the explicit project.
No routing fallback or product contract change is permitted.
