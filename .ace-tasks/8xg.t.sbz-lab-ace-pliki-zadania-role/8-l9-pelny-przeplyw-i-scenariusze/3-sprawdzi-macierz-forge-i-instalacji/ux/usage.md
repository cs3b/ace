# Sprawdzić macierz forge i instalacji — scenariusze użycia

## Interfejs

Istniejące testy i scenariusze ACE; lokalne gemy, świeże środowisko, zapis wyników przy zadaniu. Bez nowego frameworka odbioru.

Scenariusze opisują kontrakt zachowania; nie deklarują, że nowe komendy lub funkcje już istnieją.

## Przebieg poprawny

Wywołanie / wejście: Przenieść potrzebną macierz qkc: lokalny Git, GitHub, domyślne i nazwane Forgejo; task/issues, worktree/PR, review, integracja i rozwiązywanie workflow. Osobno świeża i przerwana instalacja.

Oczekiwany wynik: Działają właściwe URL i wybór forge, task/issue i PR lifecycle oraz przegląd i integracja; wyniki wskazują scenariusz, provider, wersje, komendę, wynik i raport.

## Błąd lub przerwanie

Wywołanie / sytuacja: użyć tego samego interfejsu w warunkach braku wymaganej gotowości, błędu lub przerwania wskazanych poniżej.

Oczekiwany wynik: Błędny lub niejednoznaczny serwer, brak uprawnień, offline, zmiana kandydata i niedostępne środowisko są jawne. Niewykonany wymagany scenariusz nie jest zaliczany.

## Reguły wspólne

Reguły wspólne są częścią tej specyfikacji: [kontrakt programu](.ace-tasks/8xg.t.sbz-lab-ace-pliki-zadania-role/contract.md). Obowiązuje zatwierdzony model plikowy; stare materiały są źródłem kontekstu, nie nakazem zachowania ich architektury.
