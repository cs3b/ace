# Forgejo provider transport hygiene: IssueApi on shared HttpClient, fj timeout reaping, review-path hardening

## Outcome

The Forgejo provider has one audited transport per surface: issue
operations ride the shared repository-bound `HttpClient` (Faraday,
ADR-010) with the same token, pagination, redirect, and status
classification as the PR lifecycle, and the `fj` subprocess layer cannot
leave orphaned processes behind.

## Verified findings (review 8x33sq, 2026-10-04)

All pre-existing at the 8x2.t.z78 delivery; not introduced by it.

- `IssueApi` uses Net::HTTP directly (ADR-010 violation) and duplicates
  token handling, pagination, redirect rejection, and status
  classification with different mutation-error semantics than
  `HttpClient`. Migrate issue operations onto `HttpClient`, preserving
  the intended 409/422 uncertainty classification for issue-sync
  mutations explicitly.
- `CliExecutor` (`cli_executor.rb:179-190`): `Timeout.timeout` around
  `Open3.capture3` interrupts the Ruby thread but leaves the spawned
  `fj` process running; track the child PID and terminate and reap it
  on timeout. Timeout error text should omit raw argv (may include
  titles/bodies).
- Review-comment path hardening: escape refs in repository file
  requests where the API route is built from caller input; validate
  paginated comment entry shapes before indexing; session lock files in
  the shared temp dir are world-readable and never cleaned up — use
  0600 and remove on release.

## Boundaries

No public contract change: normalized evidence, CLI surface, and error
taxonomy stay as delivered by 8x2.t.z78. The 409/422 mutation
classification for issue sync is behavioral and needs its fixtures
updated explicitly, not silently relaxed.

## Acceptance and verification

- [ ] SC1: Issue operations run on `HttpClient`; no Net::HTTP use
  remains in ace-git-forgejo; issue-sync 409/422 uncertainty behavior
  is covered by explicit tests.
- [ ] SC2: A timing-out `fj` command leaves no live child process
  (proven by a test that observes the process table or the runner
  contract); timeout errors carry no raw argv.
- [ ] SC3: Repository-file routes escape caller input; malformed
  paginated comment entries fail closed; session locks are 0600 and
  cleaned up.
- [ ] SC4: ace-git-forgejo all targets plus impacted consumer packages
  green; independent exact-source review converges.
