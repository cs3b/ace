No mocked accepted-submit result can satisfy consumed. E2E requires two equal queued payloads and unrelated same text, busy followUp, reconnect/lost add reply, compaction/read truncation, fork/reload/retirement and generation change between observe/sign/reconcile. Include direct worker attempts to replace artifact/config/source or invoke signer with invented observer ID. Supersession races must positively show the old exact entry cannot execute, not poll until absent.

Run affected ACE package checks through source `bin/ace-test`, then `bin/ace-test-suite` default fast suite. Installed scenario records provider versions/source SHA, exact commands and sanitized native add/item/turn or eviction facts plus real UID/key-fingerprint boundaries.
