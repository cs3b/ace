# Test responsibility map

All attribution behavior is high risk. ExecutionEvidence integration tests own completion schema, exact process/package/entry identity, explicit zero selection, exclusive atomic publication, missing/malformed/mismatched evidence, and mixed report identities. Real ReportStorage tests own concurrent fixed-clock allocation and latest replacement without overwrites. ProcessMonitor integration tests own controlled A/B overlap in both verdict directions, immutable capture, duplicate concurrent children, exit/timeout/interrupt precedence and absent completion failure. Aggregator and display tests own separate entry state and captured counts/links with no filesystem/latest reads. Real CLI fixtures own saved/no-save, selection and explicit zero completion from an actual ace-test child; full suite execution owns unchanged configured selections.

Only process timing/environment is controlled. Filesystem/report storage, completion serialization, orchestration and CLI child are real; no paid providers, native/VM/privilege probes. Barriers coordinate concurrency; allocation is checked under fixed Time.now.
