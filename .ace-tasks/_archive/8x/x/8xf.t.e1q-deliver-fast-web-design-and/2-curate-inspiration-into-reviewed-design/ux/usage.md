# Curate inspiration into reviewed design improvements: usage contract

## Happy path

/as-design-look-for-inspiration [--surface shared|site|app]; ace-design validate; use documented weekly prompt with external scheduler.

Expected: User invokes a periodic research workflow and receives either no actionable changes, a partial-source report, or a tested concrete package improvement ready for review.

## Invalid input

Invalid surfaces are rejected; unavailable sources produce an explicitly partial research report; unchanged revisions produce no duplicate proposals.

## Resume

Reuse the recorded context and decisions; only requested variants or affected checks run again.
