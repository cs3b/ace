# Deliver fast web design and production workflows: usage contract

## Happy path

/as-design-site or /as-design-app → previews; choose → /as-design-site-implement or /as-design-app-implement; audit and inspiration are separate entrypoints.

Expected: A developer explores web site or web app directions quickly, iterates with feedback, then implements and verifies the selected design.

## Invalid input

A missing target/session or unavailable browser produces a specific error, preserves prior artifacts, and never claims completion.

## Resume

Reuse the recorded context and decisions; only requested variants or affected checks run again.
