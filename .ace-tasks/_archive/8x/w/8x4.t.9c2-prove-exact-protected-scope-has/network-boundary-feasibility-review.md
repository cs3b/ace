No amount of raw route/namespace/FD data or root-installed rule-file hash proves the current effective packet filter. A one-time empty listener list cannot prevent later payload listeners.

Internet responses handled by contained descendants are compatible; remote effects remain separately scoped. This boundary does not require claiming all Internet egress forbidden, but it also does not satisfy the explicit ingress/control reachability clause by itself.

Current same-User hook/private observation exchange does not provide it, and existing systemd fixed unit property reads do not export nft rules. A trusted installer config file or asserted firewall boolean cannot stand in for actual enforcement. Adding CAP_NET_ADMIN/AF_NETLINK, a root prefix or privileged policy/controller API would change approved restrictions; none recommended or authorized here. Narrowing the clause to local-writer credentials or mere listener absence would change the accepted semantic and must not be silently adopted.

Recommendation: preserve explicit unresolved network verification/installed acceptance; continue independently valid owner/lifecycle layers, refuse any final proof that depends on unavailable network enforcement evidence.
