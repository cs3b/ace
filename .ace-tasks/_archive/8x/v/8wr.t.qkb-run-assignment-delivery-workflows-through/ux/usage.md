# Forge-neutral assignment delivery — usage

## Selected provider
Input: reviewed task, assignment forge_server=forgejo-lab, explicit PR provenance and current attempt.
Expected: one draft PR identity flows through review, ready and authorized merge; result names exact provider and head.

## Independent release
Input: delivered merge plus a separate exact publication proposal.
Expected: publication consumes its valid direct, scoped standing or resolved-proposal authorization, technical gates and OTP; already authorized operations need no new proposal. If authority is absent, present the exact qjz proposal. Merge itself does not authorize publication.

## Restart
Input: lost response after PR creation with an active attempt ledger.
Expected: reconcile exact recorded server/head/provenance, adopt one matching result or retain unknown; never create a second PR or retry an uncertain merge automatically.
