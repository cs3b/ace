   the actual installed binary/CLI with valid configuration: serve must be reached, or an

2. **ONE canonical Assign journal**: producer project coordinator and privileged executor must refer

3. **Real Forgejo terminal result**: the original implementation relabelled a local ref
   effect as `remote_observation`; current source delegates to the real Forgejo provider.
   Installed terminal receipts must prove the ACTUAL Forgejo PR state via API readback
   (merged flag and merge commit SHA) for the exact PR identity and accepted candidate.
   Local git effects are not a Forgejo PR merge. Receiver must not update checked-out
   canonical main locally; ambiguous readback remains uncertain until reconciled.
4. **Trusted scoped admission refresh**: the original boot-time snapshot blocked sequential
   admission; current source reloads trusted authorization. Verify the running installed
   receiver adopts a second scoped decision admitted after the first merge, with effective
   expiry/revocation, without a per-candidate root edit or service restart.
5. **Serial advance + uncertainty discipline**: accepted request ⇒ attempt/start in the canonical
   journal; the queue advances serially against fresh main; an unaccepted request is not a working
   integrator; an uncertain result reconciles (forge readback) before any repeat.
6. **Independent review attachment + carry-forward**: final-head review attachment to the PR and the
   independent carry-forward workflow (patch-id identity chain) are part of the handoff; the
   integrator/domain executor posting its own approval does NOT count as independent review.
7. **Timeout → actionable owner**: handoff timeouts name the actionable owner in the refusal/escalation
   instead of endless holding.
8. **Deploy contract (host installs; code consumes)**: scoped config under `/etc/lab/ace-lab/`
   (forge base URL + scoped PR read/comment/merge capabilities + service policy path), root-owned;
   merge authority is bounded to the authorized repository/PR/candidate and executor identity,
   not general administration or a substitute for review/admission; receiver
   refuses with actionable "config missing: <path>" when absent. No credential bypass, no new Python
   bridge, no parallel queue.
9. **Deployed end-to-end acceptance**: two sequential PRs / rebase / merge against the real lab
   Forgejo, restart and lost-reply recovery, exercised via deployed CLI — source/fixture tests alone
   do not meet acceptance.
