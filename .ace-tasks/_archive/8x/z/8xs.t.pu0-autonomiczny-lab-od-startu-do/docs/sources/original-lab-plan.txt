
 PEŁNY PLAN — Autonomiczny Lab (stan: jest / brak / ma być)

 0. Cel końcowy (co ma być)

 ```
   JEDNO POLECENIE:  ace-overseer start
     → nadzorca wstaje z operation guide Z GEMU (nie z moich notatek)
     → ma OCZY: zespół (coworker roles) · zadania (_overseer) · worktree'e (status)
                · zdarzenia (observe) · raporty (process-reports) · PR-y (remote-watch)
     → widzi zmianę → sam podejmuje: deleguje (ace-coworker commission) · przyjmuje ·
       domyka (review→approval→merge→release→publish→install→record-in-git)
     → od Kapitana chce tylko DECYZJI/OTP (ask; odpowiada kiedy chce)
     → drugi Kapitan = kolejny odbiórca w konfiguracji
   Host = infrastruktura + awarie. Zero niankowania.
 ```
