# Responsive original launcher — draft usage

## Start under the actual launcher role

`ace-overseer work-on --task TASK --project ace --agent builder --runtime herdr`

Expected: literal installed mapping `builder`, current actual launcher credentials and one retained original foreground child. One bounded ready line joins accepted original binding; conversation accepts further instructions. A supervisor-only instance delegates rather than acquiring another UID.

This start example is not yet a complete executable contract: the stable launch-input and invocation/reconciliation fields remain under review in `readiness-review.md`. The task stays draft. The prepared definition must explicitly identify project `ace` regardless of ambient project configuration. If registration succeeds but reservation conflicts, report the retained assignment/mapping and do not launch it on another mapping. Automatic selection may advance only after an attributable refusal before any canonical registration/reservation/native effect.

## Prompt and stop the unchanged attempt

`ace-overseer prompt --project ace --agent builder --assignment ASSIGNMENT --attempt ATTEMPT --mutation steer-001 --expected-generation 12 --file instruction.txt`

`ace-overseer stop --project ace --agent builder --assignment ASSIGNMENT --attempt ATTEMPT --mutation stop-001 --expected-generation 14`

Expected: real protected owner outcomes; submitted never implies consumption. Lost acknowledgments are not resent. Stop/pane close alone never permits physical cleanup. The original child exits only after actual authenticated terminal and reservation release.

After a lost prompt reply, use `ace-overseer prompt --status --project ace --agent builder --assignment ASSIGNMENT --attempt ATTEMPT --mutation steer-001`. This lookup sends no prompt and supplies neither input nor expected generation. An explicit identical mutation retry retains the original tuple, text and generation; changed input refuses. Missing or ambiguous attempt selection never chooses the newest attempt. Full reviewed steering semantics are in `cli-selection-and-retry-contract.md`.

## Stalled decision or new Captain direction

Wake the project-overseer while HITL resolution is stalled; then redirect the accepted task scope.

Expected: deferred resolver within five seconds, usable status/conversation, existing acknowledged-delivery sixteen-hour policy, revised/superseded attributable proposal and safe stop request. Uncertain old work still occupies its slot; no replacement launch or fabricated approval.
