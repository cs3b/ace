# Controlled Git removal mechanics responsibility

Specification feasibility only; no protected prune capability implementation or privileged execution.

The ace-git-worktree feature test creates an ordinary temporary linked worktree and executes maintained Git builtins. It proves dirty tracked plus untracked data causes ordinary removal refusal, move retains captured identity, single internal force removes the captured target while external exact-byte preservation and branch survive, and ignored-only data is not protected by Git cleanliness. Canonical all-root/authentication/preservation gating and public force refusal remain unimplemented child success criteria and must receive actual owner tests before promotion.

Command: `bin/ace-test ace-git-worktree ace-git-worktree/test/feat/protected_prune_git_semantics_test.rb --timeout 60`.
