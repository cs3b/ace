# Register Pi/Z.AI GLM 5.3 family in provider registry and default to glm-5.3-flash

## Context

Live Pi CLI 0.84.2 catalog (`pi --list-models glm-5.3`) exposes exactly three Z.AI GLM 5.3 models:
`zai/glm-5.3`, `zai/glm-5.3-flash`, `zai/glm-5.3-highspeed`. ACE provider registries still
default to `zai/glm-5.1` / `zai/glm-5-turbo`, which are no longer live targets.

## Spec

1. Update both tracked provider registries to byte-identical content:
   - `.ace/llm/providers/pi.yml`
   - `ace-llm-providers-cli/.ace-defaults/llm/providers/pi.yml`
2. Register exactly the three live GLM 5.3 model IDs; remove obsolete GLM entries
   (`zai/glm-4.7`, `zai/glm-4.6`, `zai/glm-4.5`, `zai/glm-5.1`, `zai/glm-5-turbo`) from the
   active surface.
3. Aliases:
   - global `pi` -> `pi:zai/glm-5.3-flash` (routine default)
   - model `glm` -> `zai/glm-5.3`
   - model `glmflash` -> `zai/glm-5.3-flash`
   - model `glmhighspeed` -> `zai/glm-5.3-highspeed`
   - preserve unrelated valid aliases (e.g. `gpt`); drop obsolete GLM aliases
     (`glmturbo`).
4. Tests: full slash-containing selectors and all aliases resolve without truncation;
   unknown models fail closed; `--no-fallback` preserves one exact provider/model target.
   Do not rewrite parser code unless a failing regression test proves it necessary.
5. Bump only packages whose shipped bytes/runtime behavior changed
   (`ace-llm-providers-cli`); update changelog; gem must build. Do not publish.
